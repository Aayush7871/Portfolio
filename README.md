# Aayush Raj Portfolio

A dark-first, responsive personal portfolio built with React, TypeScript, Tailwind CSS, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Open the local address printed by Vite. To create a production build, run:

```bash
npm run build
```

## Personalise links

Edit [src/data/portfolio.ts](src/data/portfolio.ts) to replace these configuration values:

- `GITHUB_WEATHER_URL`
- `GITHUB_SMARTATTEND_URL`

All project, skills, social, and focus content is kept in the same data file for simple future updates.
